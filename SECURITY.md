# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/s4k4tech/ha-piyolog/security/advisories/new).
Do not open a public issue.

**Never include a real PiyoLog feed URL** in a report, log or screenshot. The URL contains a secret and works as a credential.
If you posted one by accident, revoke the feed in PiyoLog and create a new one.

## Supported versions

Only the latest release is supported.
